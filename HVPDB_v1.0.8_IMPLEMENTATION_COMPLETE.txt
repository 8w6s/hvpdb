     ├─ Audit logging

[✅] FEATURE 2: GraphQL API Endpoint
     Status: Fully Implemented
     Endpoint: POST /graphql
     Features:
     ├─ Auto-generated from database structure
     ├─ Query groups list
     ├─ Query documents with filters
     ├─ Graceful fallback if strawberry missing
     └─ Same authentication as REST

     Queries:
     ├─ groups() → List all groups
     └─ groupDocs(group_name, query_json) → Fetch docs

[✅] FEATURE 3: Query Explain & Profiler
     Status: Fully Implemented
     Methods:
     ├─ explain(query) → Execution plan
     └─ profile(operation, query) → Performance metrics

     explain() returns:
     ├─ Execution strategy (unique_index / index_scan / full_scan)
     ├─ Index usage details
     ├─ Estimated documents scanned
     └─ Explain time (ms)

     profile() returns:
     ├─ Operation type
     ├─ Documents found/affected
     ├─ Execution time (ms)
     ├─ Memory delta (bytes)
     └─ Success status

[✅] FEATURE 4: Default Values in Schema
     Status: Fully Integrated
     Support:
     ├─ Pydantic Field(default=...)
     ├─ Pydantic Field(default_factory=...)
     └─ Auto-applied on insert

     Applied to:
     └─ group.insert() method
